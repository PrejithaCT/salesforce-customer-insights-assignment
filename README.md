# salesforce-customer-insights-assignment

This repository contains the Salesforce implementation for the Customer Insights assignment.

## Component
`customerInsights`

## Features
- Input Customer ID
- Display customer basic information
- Display recent activity
- Expand/collapse activity section
- Display Engagement Score and Intent Level
- Display Product Interest
- Get Recommendation button
- Apex controller for customer insight and recommendation logic

## Notes
Website activity is mocked to simulate Data Cloud engagement data. Contact, Task, and Event data can be retrieved from Salesforce CRM.
